# Leo's Fortune (fan-made tribute)

A browser platformer you can install on your phone like an app.

**Play:** https://rafidk9.github.io/leos-fortune/

- **iPhone:** open the link in Safari → Share → *Add to Home Screen*.
- **Android:** open the link in Chrome → ⋮ menu → *Install app* / *Add to Home screen*.

Works offline after the first load. Play in landscape.
